# 💬 Real-Time Chat App with AI Integration

## 🎯 Portfolio Project - Always Works!

A full-stack real-time messaging application featuring AI assistant integration. Perfect for demonstrations and interviews.

# Frontend Live: https://convo-ai-xi.vercel.app/(https://convo-ai-xi.vercel.app/)

## 🚀 Features

- **Real-time Messaging** - Instant messages between users
- **AI Assistant** - Built-in AI chat (portfolio mode - always works)
- **User Authentication** - JWT-based secure login
- **Online Users** - See who's currently online
- **Responsive Design** - Works on all devices

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, Socket.io
- **Database**: MongoDB
- **Authentication**: JWT
- **AI**: OpenAI GPT integration (optional)

## 🎮 Demo Instructions

1. **Run the app** - It works immediately!
2. **Open two browser tabs** to simulate multiple users
3. **Login with different accounts** in each tab
4. **Start chatting** and use AI commands:
   - `@ai hello` - Test basic AI
   - `@ai portfolio` - Learn about the project
   - `@ai how does this work` - Technical details
   - `@ai who is obama` - Knowledge questions
